ON-DEVICE BY DESIGN

A short, local route from prompt to reply.

Your browser talks to the Puffx server on this computer. The server passes the prompt to Ollama, which runs the model stored on your device.

PICK THE SIZE THAT FITS

Start small, switch when you’re ready.

Download size is disk space, not the total memory needed while a model runs. Smaller models need fewer resources but may give simpler answers.

SMALLESTQwen 2.5 · 0.5B~398 MBFor limited storage or memory
COMPACTQwen 2.5 · 1.5B~986 MBA small step up in capability
DEFAULT · RECOMMENDEDQwen 2.5 · 3B~1.9 GBBalanced size and capability
LARGERQwen 2.5 · 7B~4.7 GBNeeds more storage and memory

Sizes are approximate and may change with model updates. Ollama downloads model weights separately.

THREE STEPS TO YOUR FIRST CHAT

Get started locally.

Core requirements: Python 3.11+, Ollama, and one downloaded model. The first download needs internet; after setup, core chat works offline.

01

Install the basics

Install Python 3.11 or newer and Ollama for your operating system.

02

Download a model

In a terminal, run:

ollama pull qwen2.5:3b
03

Start Puffx

Run the local server and open http://127.0.0.1:8000 in a browser on the same computer.
