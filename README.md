# OfflineGPT

A private, ChatGPT-inspired chat app that runs an open-weight AI model on your own computer. Once Ollama and the model are installed, chats work without an internet connection. No API key or cloud account is used.

> OfflineGPT is an independent project and is not affiliated with OpenAI. It does not run ChatGPT or OpenAI models. It uses a local model through Ollama.

## Features

- ChatGPT-inspired responsive chat interface, conversation history, and dark/light themes
- Local inference through Ollama; prompts are sent only to your local Ollama server
- Chat history is stored in your browser's local storage
- No cloud API key, subscription, or telemetry

## Quick start (Windows)

1. Install [Ollama](https://ollama.com/download).
2. Open PowerShell and download a model once:
   ```powershell
   ollama pull qwen2.5:3b
   ```
   The download needs internet. After it finishes, the model runs locally and you can disconnect.
3. Install Python 3.10 or newer if needed.
4. In this folder, run:
   ```powershell
   python server.py
   ```
5. Open [http://127.0.0.1:8000](http://127.0.0.1:8000).

Ollama usually starts automatically after installation. If it is not running, open the Ollama app first. The default model is `qwen2.5:3b`; it can be changed with an environment variable:

```powershell
$env:OLLAMA_MODEL = "llama3.2:3b"
python server.py
```

Ollama must have that model downloaded (for example, `ollama pull llama3.2:3b`). Different models vary in quality and hardware requirements. 3B models are a practical starting point; generation speed depends on your computer.

## Run on macOS / Linux

Install Ollama and Python 3, run `ollama pull qwen2.5:3b`, then start `python3 server.py` and visit `http://127.0.0.1:8000`.

## Privacy and limitations

The browser talks to the local Python server, which forwards chat messages to Ollama at `127.0.0.1:11434`. The app itself does not make cloud AI requests. The first model download requires internet; after installation, local chat can run offline. Responses are generated by the selected open model and can be inaccurate. Browser history stays in local storage on that browser/device.
